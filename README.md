# Limpieza-fotos-iPhone
Atajo en el iPhone para hacer limpieza de la galería:

Agrupa fotos pasadas en un solo álbum para que puedas revisar y borrar rápidamente, evitando acumulaciones.

# Requisitos
Crear un álbum en tu app Fotos de iOS que se llame exactamente **Este día** / Cambiar este nombre en el atajo.
Excluir todos los álbumes compartidos para que no den error. 

# Instalación
* **Rápida:** Descargarlo desde iCloud 👉 **[Instalar desde iCloud]([Pega_aqui_tu_enlace_de_iCloud])**
* **Manual:** Descarga el archivo `.shortcut` de este repositorio y ábrelo en tu dispositivo.

## 🔐 Permisos
Al ejecutarlo por primera vez, iOS te pedirá permiso para:
* **Eliminar fotos:** Para vaciar el álbum "Este día" de la revisión anterior. *(Nota: solo las quita del álbum, no las borra de tu carrete).*
* **Guardar fotos:** Para añadir las nuevas fotos que vas a revisar hoy.

## 💡 Qué hace exactamente
Al ejecutar el atajo, sigue este flujo automático:
1. **Vacía** el álbum "Este día".
2. **Busca** las fotos de ayer y las de este mismo día exacto en los últimos 5 años.
3. **Excluye** las fotos que ya tienes guardadas en tus álbumes compartidos (Cascais 2025, Gredos, Bilbao, amigos, etc.).
4. **Agrupa** el resultado en el álbum "Este día", dejándolo listo para que entres y borres directamente lo que no te sirva.
